Personal research project

Application of diffusion models and/or autoencoder to denoise electrocardiogram (ECG) signals.

Methodology

  • Noise simulation: Generated various physiological noises (Gaussian, electrode motion, muscle artifacts) on real ECG signals
  • Model training: Trained a Denoising Diffusion Probabilistic Model (DDPM) and/or autoencoder
  • Evaluation: Assessed performance using MSE, SNR, and correlation metrics

Technologies

  • PyTorch
  • Diffusion Models (DDPM)
  • Autoencoder
  • Signal Processing
  • ECG Data Analysis
